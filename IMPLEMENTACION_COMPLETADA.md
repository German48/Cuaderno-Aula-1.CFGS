## 💡 Ejemplos de Uso Rápido

### Optimizar Imagen

```javascript
import { processImage } from './utils/imageOptimizer';

const { photo, thumbnail } = await processImage(file);
// photo: imagen comprimida
// thumbnail: miniatura 100x100
```

### Crear Backup

```javascript
import { backupManager } from './utils/backupManager';

await backupManager.createBackup();
// Backup creado automáticamente
```

### Exportar PDF

```javascript
import { PDFExporter } from './utils/pdfExporter';

const exporter = new PDFExporter(settings);
exporter.exportStudentList(students);
// PDF descargado automáticamente
```

### Usar Tooltips

```jsx
import { Tooltip } from './components/Tooltip';

<Tooltip content="Guardar cambios">
  <button>Guardar</button>
</Tooltip>
```

### Atajos de Teclado

```javascript
import { useKeyboardShortcuts } from './hooks/useKeyboardShortcuts';

const shortcuts = [
  { key: 's', ctrl: true, action: save }
];

useKeyboardShortcuts(shortcuts);
```
